# WILKERSTAT 6309

A simple, no-install web app for exploring Wilkerstat maps in Tabalong Regency, South Kalimantan.

**Wilkerstat** (wilayah kerja statistik) is the framework used by Badan Pusat Statistik (BPS) for conducting
censuses and surveys. It provides the geographic marks used to organize and identify statistical working areas,
updated yearly at the end of every year.

## Access

The application can be accessed directly through this link:

**[WILKERSTAT 6309](https://tiomultazem.github.io/wilkerstat-6309/)**

No installation is required. Simply open the link in a web browser.
